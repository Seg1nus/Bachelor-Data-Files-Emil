# Bachelor-Data-Files
This serves as a supplement for data set and python files in the appendix of the thesis "Machine Learning Hidden Structures in Scattering Amplitudes" done at University of Southern Denmark by Emil Dinesen Villekjær.

## Contents
- `loop1.txt` to `loop6.txt` — [Full loop data sets]
- `AFloop1.txt` to `AFloop8.txt` - [{a,f}-restricted loop data sets]
- `initial6.py`, `evaluate6.py`, `run_evo6.py` and `main6.py` - [Initial python files and result from ShinkaEvolve in 6th loop order experiment.]
- `initialAF.py`, `evaluateAF.py`, `run_evoAF.py` and `mainAF.py` - [Initial python files and result from ShinkaEvolve in {a,f}-word restricted experiment.]
- `bestformula6.py` - [Result from Claude Code in 6th loop order experiment.]
- `bestformulaAF.py` - [Result from Claude Code in {a,f}-word restricted experiment.]

## Description
The data sets are the raw data files used in the project. The python files are the full raw unedited refered to in the thesis.

## Citation
Emil Dinesen Villekjær, "Machine Learning Hidden Structures in Scattering Amplitudes", University of Southern Denmark, 2026.
